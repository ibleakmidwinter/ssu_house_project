# 방값판독기

> 동네별 전월세 시세 분석 및 적정성 판독기
> 2026-2학기 AI개발과실전 팀 프로젝트 6조

지역과 매물 조건을 입력하면 **국토교통부 연립다세대 전월세 실거래가**로 주변 시세를 계산하고,
내 매물이 **적정 가격인지(4등급)** 와 **허위매물 신호가 있는지** 를 판정합니다.

---

## 빠르게 실행하기

```bash
# 1) 화면만 확인 (서버 함수 없이, 샘플 데이터로 전체 흐름 체험 가능)
python3 -m http.server 3000
# → http://localhost:3000 접속 후 "샘플 데이터로 먼저 보기" 클릭

# 2) 실거래 API까지 포함해 실행
npx vercel dev
# → http://localhost:3000
```

빌드 단계가 없습니다. `index.html`을 브라우저로 바로 열어도 화면이 뜹니다.

### 환경변수 (`.env.local`)

```
OPENROUTER_API_KEY=            # 없어도 됨 (없으면 AI 설명이 자동 생성 문구로 대체)
OPENROUTER_MODEL=google/gemma-4-26b-a4b-it:free
DATA_GO_KR_SERVICE_KEY=        # 공공데이터포털 인증키 (실거래 조회에 필요)
```

`.env.local`은 `.gitignore`에 등록되어 커밋되지 않습니다. 배포 시에는 Vercel 대시보드의
**Settings → Environment Variables**에 같은 이름으로 등록하세요.

### 무료 모델에 대해 알아야 할 점

무료 모델은 여러 사용자가 공유 풀을 쓰기 때문에 **HTTP 429(rate limit)가 자주 납니다.**
또 상당수가 추론(reasoning) 모델이라 `max_tokens`를 추론에 먼저 써버려 본문이 빈 채로 오기도 합니다.
그래서 `api/parse-query.js`는 이렇게 대응합니다.

- 1순위 모델이 막히면 **무료 후보 5개를 차례로 시도** (`FALLBACK_MODELS`)
- 추론 토큰을 감안해 **필요량의 3배 이상 토큰 예산**을 잡고 `reasoning: { effort: 'low' }` 요청
- `content`가 비면 `reasoning` 필드도 확인
- 그래도 실패하면 **템플릿·규칙 기반 폴백** (화면은 항상 채워짐)

측정된 AI 성공률은 약 **7~8할**이고, 나머지는 자동 생성 문구로 대체됩니다.
다른 모델을 쓰려면 `.env.local`의 `OPENROUTER_MODEL`만 바꾸면 됩니다.

공공데이터포털에서 **"국토교통부_연립다세대 전월세 실거래가 자료"** 활용신청이 승인되어 있어야 합니다.

## 동작 방식

```
[입력]  지역 · 주택유형 · 전세/월세 · 보증금/월세 · 전용면적 · 전월세전환율
   ↓
[수집]  api/transactions.js → 국토교통부 RHRent API (XML) 최근 12개월
   ↓    resultCode 000 확인 → <item> 파싱 → 쉼표 제거 후 숫자 변환 → 중복 제거
[추출]  같은 동네 → 같은 주택유형 → 전용면적 ±15% (5건 미만이면 ±25% → 조건 해제)
   ↓    IQR 1.5배 이상치 제거
[환산]  환산보증금 = 보증금 + (월세 × 12 ÷ 전환율)        ← 전세·월세를 한 축으로
   ↓
[통계]  최저 · 하위25%(Q1) · 중앙값 · 평균 · 상위25%(Q3) · 최고
   ↓
[판정]  괴리율(%) = (내 매물 환산보증금 − 중앙값) ÷ 중앙값 × 100
   ↓    🟢안심(<-5%) 🔵적정(-5~10%) 🟡주의(10~20%) 🔴위험(>20%)
[점검]  허위매물 신호 R1~R8 규칙 채점 (0~100점) — 표본 부족 시 점수 상한
   ↓
[설명]  api/interpret.js, api/appraise.js → OpenRouter 무료 모델이 쉬운 말로 풀어 설명
        (숫자는 전부 코드가 계산한 값. AI는 설명만 하고 검증을 통과해야 채택)
```

### 판정 등급

| 등급 | 괴리율 | 의미 |
|---|---|---|
| 🟢 안심 | -5% 미만 | 주변 시세보다 저렴한 편 |
| 🔵 적정 | -5% ~ +10% | 적정 시세 범위 |
| 🟡 주의 | +10% ~ +20% | 주변 평균보다 다소 높음 |
| 🔴 위험 | +20% 초과 | 주변 시세보다 현저히 비쌈 |

> 가격이 **너무 싼** 경우는 등급상 '안심'이지만 미끼 매물일 수 있습니다.
> 그래서 허위매물 신호 점검을 따로 두고, 둘이 충돌하면 화면 상단에 경고를 띄웁니다.

### 허위매물 신호

| ID | 신호 | 배점 |
|---|---|---|
| R1 / R1+ | 이례적 저가(하위10%) / 극단적 저가(하위5% 또는 −2.5σ) | +15 / +20 |
| R2 | 면적-가격 불일치 (넓은데 쌈) | +15 |
| R3 | 비현실적 조건 조합 (신축+넓음+저가) | +15 |
| R4 | 관리비가 월세의 35% 초과 | +12 |
| R5 / R5+ | 주소 비공개 / 중개사 등록번호도 없음 | +10 / +8 |
| R6 | 1개월 이상 게시된 저가 매물 | +10 |
| R7 | 비교할 실거래가 5건 미만 | +8 |
| R8 | 비슷한 가격의 실거래가 있음 | **−5** |

표본이 적으면(10건 미만 49점 / 30건 미만 74점) 점수 상한을 둡니다. 데이터가 빈약할 때
단정적 판정은 오판 위험이 더 크기 때문입니다.

## 예외 처리

| 상황 | 동작 |
|---|---|
| 비교 거래 5건 미만 | 면적 범위를 ±25%로 확장 → 그래도 부족하면 면적 조건 해제. 화면에 확장 안내 배지 표시 |
| 해당 동 거래 부족 | 시군구 전체로 자동 확장 + 안내 배지 |
| 조건에 맞는 거래 0건 | "면적이나 지역·주택유형을 넓혀 다시 조회해 보세요" 안내 |
| 인증키 없음 / 활용신청 미승인 / 일일 한도 초과 | **Mock 샘플 데이터로 폴백** + "샘플 데이터" 배지 |
| OpenRouter 실패 / 키 없음 | 템플릿 기반 설명으로 폴백 (판정 결과는 그대로 표시) |
| 지역 코드가 맞지 않음 | 입력 폼의 "시군구 코드 직접 입력"으로 보정 |
| AI가 없는 숫자를 지어냄 | 숫자 검증 실패 시 응답 폐기 → 재시도 → 템플릿 폴백 |
| 무료 모델 429 / 빈 응답 | 무료 후보 5개 순차 시도 → 전부 실패 시 템플릿 폴백 |
| AI가 금액을 잘못 옮겨 씀 | 완성된 금액 문자열을 주고 복사만 시키고, 그 문자열 밖의 숫자는 거부 |
| AI가 엉뚱한 지역을 답함 | 랜드마크·법정동 표로 재검증 후 폼에 채우기만 함 (사용자가 확인·수정) |

## 파일 구조

```
/
├── index.html      # 전체 화면 (좌: 입력 패널 / 우: 결과 대시보드)
├── style.css       # 전체 스타일 + 반응형 (640px / 1024px)
├── script.js       # 전체 클라이언트 로직 (섹션 주석으로 구획)
├── api/            # Vercel 서버리스 함수 — 외부 API 호출은 여기서만
│   ├── transactions.js   # 실거래가 수집 · XML 파싱 · 정제
│   ├── analyze.js        # 주변 시군구 일괄 수집
│   ├── parse-query.js    # 자연어 입력 파싱 (OpenRouter) + 공통 호출 함수
│   ├── interpret.js      # 시세 통계 해설 (OpenRouter)
│   └── appraise.js       # 판정 결과 해설·확인 질문 (OpenRouter)
├── data/           # 정적 JSON (지역코드·랜드마크·인접관계·규칙·Mock)
├── AGENTS.md       # 코드 작성 규칙
└── PRD_step1~3.md  # 기획 문서
```

`script.js` 섹션: `1.상태 → 2.유틸 → 3.통계 → 4.API호출 → 5.SVG차트 → 6.렌더링 → 7.이벤트 → 8.자체점검`

프레임워크·빌드 도구·외부 라이브러리를 쓰지 않습니다. 차트는 SVG를 직접 생성합니다. 자세한 규칙은 [AGENTS.md](AGENTS.md).

브라우저 콘솔에서:


터미널에서 검증한 결과:

| 항목 | 결과 |
|---|---|
| `__selfTest()` 단위 테스트 | **41/41 통과** |
| 서버리스 함수 폴백 경로 | **17/17 통과** (키 없을 때 405/400/Mock/템플릿 폴백) |
| 공공데이터 API 실제 연결 | `resultCode 000` · 동작구 2025-09 **413건** |
| 실데이터 종단 테스트 | 동작구 12개월 **5,276건 수집 (0.7초)** · 숫자 변환 실패 **0건** |
| 판정 시나리오 | 정상 / +25% 위험 / +15% 주의 / -10% 안심 / 초저가 의심 / 월세 / 표본부족 확장 / 0건 — 전부 정상 |
| OpenRouter 실제 호출 | `parse-query` 3/3 · `interpret` 2/3 · `appraise` 2/3 성공 (3.3~9.5초), 실패 시 템플릿 폴백 |

### 주요 테스트 케이스

| 입력 | 기대 | 결과 |
|---|---|---|
| 전세 1억 4,000 (중앙값 근처) | 🟢 안심 또는 🔵 적정 | 괴리율 -7.7% → 🟢 안심 |
| 중앙값 +25% | 🔴 위험 | 괴리율 25% → 🔴 위험 |
| 중앙값 +15% | 🟡 주의 | 괴리율 15% → 🟡 주의 |
| 월세 1,000/55 @5.5% | 환산보증금 13,000 | 13,000 ✅ |
| 중앙값의 50% + 주소비공개 + 장기게시 | 허위매물 신호 다수 | 63점 · 높은 주의 · R1,R1+,R5,R5+,R6 |
| 월세 30 / 관리비 15 | 관리비 위장 신호 | R4 발동 (47점) |
| 없는 동 입력 | 시군구 전체로 확장 | 확장 배지 표시 후 정상 분석 |
